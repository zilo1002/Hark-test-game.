# 半亩·丰收

> 走进堆成山的鸡蛋里，一口气背走几百个。

一个“走路—收集—叠高—卖掉—解锁”的轻量农场小游戏，玩法参照青青农场 / Gardenscapes 农场模式的试玩广告。纯静态网页，没有外部依赖和图片素材，所有画面都由 `<canvas>` 程序绘制。手机竖屏优先，电脑用鼠标或 WASD / 方向键也能玩。

## 玩法

- **走路**：按住屏幕任意处拖动 = 虚拟摇杆。
- **收集**：走进成熟的麦田/土豆地自动收割；走进鸡蛋堆、土豆堆、番茄堆，周围的东西会被吸到头顶，叠成一根摇晃的高柱（显示数量，满了显示 MAX）。
- **卖**：走到摊位前的白框里卸货，顾客排队买走，钞票掉在地上，走过去捡起来。
- **解锁**：站在虚线格子上，钱会一张张飞进去，进度满了就“嘭”地解锁：新田地、新摊位、买鸡（+4 只）、种番茄、大背篓、跑鞋、大手、雇工、雇小车、小红车、收银员、加工机器。
- **加工**：鸡蛋放进机器变成蛋箱，番茄变成番茄酱，价钱翻好几倍。
- **关卡**：一共 10 关，每关一个小农场和一个目标（顶部进度条），完成后按用时得 1–3 颗星，钱和解锁每关重置。
- **我的农场**：关卡之间回到自家农场，用星星修篱笆、铺小路、种花、修水井、刷房子、盖风车……
- 右上角：回农场、设置（声音、震动、重置进度）。进度自动存在本机浏览器（localStorage）；浏览器不让存时照样能玩，只是关掉页面后不保留。

## 本地运行

ES 模块不能直接双击打开，起一个静态服务器：

```bash
cd 仓库根目录
python3 -m http.server
# 打开 http://localhost:8000/harvest/
```

所有路径都是相对路径，放在任何子目录下都能运行。

## 文件

```
harvest/index.html   页面骨架（HUD、农场面板、关卡选择、设置、过关卡片）
harvest/style.css    卡通风格的 DOM 界面
harvest/js/config.js 所有数值：速度、容量、价格、作物、10 个关卡的布局与解锁格子、农场修复项
harvest/js/world.js  一关的全部游戏逻辑（不碰 DOM，浏览器和平衡模拟共用）
                     沙堆高度场（数千个物品的堆积/塌落/挖洞）、收集/卸货、顾客、加工、雇工 AI、指引箭头
harvest/js/render.js 2.5D 斜俯视画布渲染：地面预渲染、按深度排序、堆的逐行绘制与遮挡剔除、物品叠柱
harvest/js/sprites.js 程序绘制的物品贴图（鸡蛋/土豆/番茄/麦捆/蛋箱/番茄酱/钞票），按缩放缓存
harvest/js/chars.js  女孩、雇工、顾客、母鸡、番茄丛、小红车、雇工小车、摊位、机器
harvest/js/icons.js  解锁格子与招牌上的小图标
harvest/js/fx.js     对象池粒子、飘字、飞钞票、彩带、震屏
harvest/js/input.js  浮动虚拟摇杆 + 键盘
harvest/js/audio.js  WebAudio 音效 + navigator.vibrate 震动
harvest/js/save.js   存档（localStorage，失败时退回内存）
harvest/js/home.js   关卡之间的农场修复场景
harvest/js/ui.js     DOM 界面
harvest/js/main.js   启动、主循环、事件 → 特效
harvest/sim/balance.mjs 无界面平衡模拟
```

## 平衡模拟

```bash
node harvest/sim/balance.mjs            # 两种玩家，每关 3 个随机种子取中位数
node harvest/sim/balance.mjs --verbose  # 列出每次解锁的时间与价格
```

模拟直接运行 `js/world.js` 的真实逻辑，机器人跟着游戏里的指引箭头走（“熟练”= 满速摇杆、0.1 秒反应；“休闲”= 80% 摇杆、0.7 秒反应），报告每关完成时间、每次解锁时间、第一次解锁 / 第一次买鸡 / 小红车的时间。
