# 半亩·丰收

> 走进花田，一刀下去，花朵飞上背后的高塔。

一个“走路—收割—叠高—出售—解锁”的农场小游戏，画面和手感参照 Gardenscapes / Homescapes 的花田模式试玩广告。**v3 是 3D 版**：Three.js（`vendor/three.module.min.js`，本地文件，离线可用）渲染的低多边形庄园，圆滚滚的卡通小人（走路、挥镰刀、抱着高塔的动画），成千上万株可以一路割过去的花和庄稼，背上越堆越高的花塔，排队买花的顾客。没有图片素材，所有模型都由几何体拼出来。**横屏优先**，竖屏也能玩；电脑用鼠标拖动或 WASD / 方向键。另有离线安卓 APK（见 `android-harvest/`），**在 [Releases](https://github.com/zilo1002/Hark-test-game./releases/latest) 下载 `banmu-harvest.apk`**（网页版已下线）。

## 玩法

- **走路**：左下角的半透明摇杆——按住屏幕任意处拖动。
- **收割**：走进成熟的麦田、郁金香、金盏花、玫瑰，周围一圈**同一帧全部割下**（半径内一株不留，只有背篓满了才停），花朵喷向空中、划着弧线落到怀里的高塔上，田里留下一条整齐、颜色明显更深的割痕；割过的地方先是一截截茬（约 4 秒），再冒芽，过一会儿重新开花。
- **震动**：割的时候持续“嗡嗡”震（限频，不会糊成一片），卖出、解锁、过关更强。设置里可以关。安卓 APK 里用系统 VibrationEffect（可控强度），浏览器里用 navigator.vibrate（iPhone 的 Safari 不支持网页震动）。
- **捡堆**：鸡蛋堆、土豆堆、番茄堆——走进去，周围的东西会被吸到背上。
- **出售**：把东西背到蓝色「出售」台前的虚线框里卸货，顾客排队买走，钞票堆在旁边的深色格子上，走过去收钱。
- **解锁**：站在青色虚线格子上付钱，满了“嘭”一下解锁：新花圃、雇园丁（会自己去割、自己送货）、雇小车、割草机（坐上去一次割一大片）、大花篮、跑鞋、大剪刀、买鸡、种番茄、出售台、收银员、加工机器、快机器。白色箭头一直指着下一步。
- **加工**：花束机（金盏花→花束）、花篮机（郁金香→花篮）、香水机（玫瑰→香水）、蛋箱机、番茄酱机，做好的东西直接送到出售台上。
- **关卡**：38 关，每关一个新作物、新机器或新玩法；完成后按用时得 1–3 颗星。
- **我的庄园**：关卡之间回到庄园，用星星修铁门、铺石子路、修喷泉、种樱花树、盖凉亭和温室、粉刷洋房……
- 右上角红色 ✕：暂停（继续 / 设置 / 选择关卡 / 回到庄园）。进度自动存在本机浏览器（localStorage）；浏览器不让存时照样能玩，只是关掉页面后不保留。

## 本地运行

ES 模块不能直接双击打开，起一个静态服务器：

```bash
cd 仓库根目录
python3 -m http.server
# 打开 http://localhost:8000/harvest/
```

所有路径都是相对路径，放在任何子目录下都能运行。地址后加 `?debug` 会暴露 `window.__dbg`（自动截图/测试用；`__dbg.quality(0|1|2)` 手动切画质）。

## 画质自适应

三档：高（像素比 2、2048 阴影、作物也投影）、中（像素比 1.5、1024 阴影）、低（像素比 1、无阴影）。开局用高档，连续 2 秒低于约 40 帧就降一档，持续流畅 12 秒会试着升回（最多降两次后不再升）。

## 安卓 APK

`android-harvest/` 是一个只有一个 Activity 的 WebView 外壳（`com.zilo.banmuharvest`）：横屏、沉浸式全屏、常亮；游戏文件打包在 APK 的 assets 里，通过 `https://appassets.androidplatform.net/harvest/` 本地提供（离线可玩、存档照常）；`window.AndroidHaptics.vibrate(ms, 振幅1-255)` 桥接系统震动；返回键 = 暂停菜单 / 关闭弹窗。

```bash
./android-harvest/build-apk.sh   # 直接用 Android SDK（aapt2 + javac + d8 + apksigner）出 debug APK
# 或者用 Gradle（AGP 8.5.2，与 auto-clicker 同一套工具链）：cd android-harvest && gradle assembleDebug
```

## v3.2 新内容

- **背满即停**：玩家、园丁、铲车背满后不再收割（作物留在地里），玩家头顶大号闪烁的 MAX、一次强震动，箭头直接指向能收这批货的出售台/机器。容量：玩家 100（大背篓格子 ×2）、园丁 50、铲车 150、割草机 300。
- **园丁换铲车**（青色格子，图标为小铲车）：本关所有园丁（包括之后再雇的）坐上小铲车——更大收割半径、更快、后斗装 150。
- **金色作物**：约 1/150 的作物闪金光，割到直接 +10 倍单价的钱。
- **丰收狂热**：连续收割攒满能量条 → 6 秒狂热（+40% 速度、+40% 收割半径、金色拖尾、更密的震动）；背着货时能量条冻结，空手 1.5 秒不割开始回落。狂热不突破背包上限。
- **VIP 顾客**：戴金冠、头顶想要的货 ×2 气泡，付双倍并撒钞票。
- **园丁成长**：每 3 趟送货升一级（Lv1→Lv5），每级 +8% 速度、+10% 容量，头顶等级徽章。
- **洒水器**（第 2、5、8、10、12、14 关）：田地再生速度 ×2，能看到旋转的水柱。
- **店员 / 鸡蛋搬运工**：每个原本需要玩家去收钱的出售台都有「店员」格子；鸡蛋关有早早出现的「鸡蛋搬运工」，把鸡蛋从鸡舍运到出售台。
