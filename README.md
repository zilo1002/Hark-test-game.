# 半亩

> 种菜，卖菜，雇人替你干活。水墨风放置种田 + 3D 收获加工，纯静态网页，打开即玩。

另一个小游戏：**[半亩·丰收](./harvest/)** —— 走进田地收获、加工、装箱并出售，解锁新关卡、雇工和庄园。现有 67 关；当前 Android 版本为 5.1.6（versionCode 56）。**[在线试玩](https://zilo1002.github.io/Hark-test-game./harvest/)**；安卓 APK 可在 [Releases](https://github.com/zilo1002/Hark-test-game./releases/latest) 查看。版本、测试状态和关卡说明见 [harvest/README.md](./harvest/README.md)。

## ✨ 功能亮点
- **种**：点一块空地，选种子播下。作物分三个生长阶段，成熟时会泛起微光、轻轻晃动。
- **收**：点成熟的作物收进仓库（顶部显示仓库已用/容量）。仓库满了就收不进去。
- **卖**：在「集市」逐种卖出或「全部卖出」。价格每 60 秒在 ±15% 之间浮动，箭头提示涨跌。
- **订单**：集市顶部有 3 张订单（例如「镇上的面馆：小葱×10，白菜×4」），凑齐交付有额外赏钱；不想做可以「换」一单。
- **工具**（Lv1–5，图标随等级变化）
  - 锄头：一次播种 1 块 → 一整行 → 整片田，高级还省种子钱
  - 镰刀：一次收割 1 块 → 一整行 → 整片田，高级有双倍收成
  - 水壶 → 喷壶 → 水车 → 洒水器：作物长得更快
  - 推车：售价更高
  - 仓库：容量更大
- **雇工**（可以雇多个，每种都能升级速度/容量）——看他们在地里走来走去干活就是这个游戏的乐趣
  - 种地工：走到空地，播下你选的种子（可选「跟上一茬」或固定某种）
  - 收割工：走去收成熟的菜，筐满了送回仓库
  - 挑夫：仓库快满时挑去集市卖掉（会走出画面再回来）
  - 管家：仓库里的货够了，就替你去交订单，还多讨点赏钱
- **庄园等级**：按累计赚到的金币升级，解锁雇工、工具上限，田边陆续出现篱笆、谷仓、风车、灯笼、垂柳、远塔……
- 开局 2×2 块地、50 金币，地可以一路开垦到 3×4。
- **半亩·丰收**：67 关，每关一个新作物、新机器或新玩法，按用时得 1–3 颗星；夜市 61–67 关；星星商店 14 件装饰（共 108★）；庄园地图（四季山谷、夜市）可兑换切换；机器两档升级；链式专员（两台机器串联只雇一个）；售货员一次拿满、一放放满，还换大铲车；没机器的关农工收了堆木台上，柜台缺货时优先送柜台。
- **木台**：所有关卡都有平木台——原料一大块平木台，加工品另一块平木台，踩上去搬货。
- **离线收益**：离开后回来按离开时长（最多 2 小时）结算雇工产出：「你不在时，雇工替你挣了 X 金币」。

## 🔒 隐私与安全
- 不收集任何数据：没有后端、没有统计脚本、没有外部请求，整个游戏加载后完全离线运行。
- 所有存档只保存在本机浏览器的 localStorage 里，清除浏览器数据会同时清掉存档；设置（右上角齿轮）里可一键清空存档。
- 本地运行源码可完整审查，无任何混淆。

## 🛠 技术栈
- 纯静态 HTML / CSS / 原生 JavaScript（ES Modules），无构建步骤、无框架、无依赖
- 3D：Three.js（vendor/three.module.min.js，本地文件，离线可用）
- 美术：全部线描 SVG 字符串内嵌 + 几何体拼的 3D 模型，零图片资源
- 动效：CSS 动画 + Canvas/粒子效果
- 持久化：localStorage + 离线收益快进结算
- 部署：GitHub Actions 构建 APK 并发布 Release、部署 GitHub Pages，全相对路径，游戏放在 `/harvest/` 子目录运行

## 💡 使用提示
- **双击 `index.html` 打不开**：浏览器不允许 file:// 加载 ES 模块，必须起本地静态服务器：

  ```bash
  cd 本仓库目录
  python3 -m http.server
  ```

  然后打开 <http://localhost:8000>。手机和电脑在同一 Wi-Fi 下，也可用电脑的局域网 IP 访问。
- **调平衡只改 `js/config.js` / `harvest/js/config.js`**，改完跑一遍 `node sim/balance.mjs`（半亩）或 `node harvest/sim/balance.mjs`（丰收）：用一个“普通玩家”机器人跑多个随机种子，输出各关用时与星星。
- **安卓更新**：去 Releases 下载最新 APK 安装，覆盖安装即可，存档保留。
- **版本号逢 10 进位**：4.9.9 之后是 5.0.0，没有 4.9.10；5.1.9 之后是 5.2.0。
- **Pages 部署状态**在仓库的 **Actions → pages build and deployment** 查看；「半亩·丰收」在线页已验证可访问。
