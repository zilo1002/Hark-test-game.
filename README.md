# 半亩

> 种菜，卖菜，雇人替你干活。

一个月下水墨风的放置种田小游戏。纯静态网页：没有构建步骤、没有外部依赖、不联网，打开即玩。手机竖屏优先，电脑用鼠标也行。

## 玩法

1. **种**：点一块空地，选种子播下。作物分三个生长阶段，成熟时会泛起微光、轻轻晃动。
2. **收**：点成熟的作物收进仓库（顶部显示 仓库 已用/容量）。仓库满了就收不进去。
3. **卖**：在「集市」逐种卖出或「全部卖出」。价格每 60 秒在 ±15% 之间浮动，箭头提示涨跌。
4. **订单**：集市顶部有 3 张订单（例如「镇上的面馆：小葱×10，白菜×4」），凑齐交付有额外赏钱；不想做可以「换」一单。
5. **工具**（Lv1–5，图标随等级变化）
   - 锄头：一次播种 1 块 → 一整行 → 整片田，高级还省种子钱
   - 镰刀：一次收割 1 块 → 一整行 → 整片田，高级有双倍收成
   - 水壶 → 喷壶 → 水车 → 洒水器：作物长得更快
   - 推车：售价更高
   - 仓库：容量更大
6. **雇工**（可以雇多个，每种都能升级速度/容量）——看他们在地里走来走去干活就是这个游戏的乐趣
   - 种地工：走到空地，播下你选的种子（可选「跟上一茬」或固定某种）
   - 收割工：走去收成熟的菜，筐满了送回仓库
   - 挑夫：仓库快满时挑去集市卖掉（会走出画面再回来）
   - 管家：仓库里的货够了，就替你去交订单，还多讨点赏钱
7. **庄园等级**：按累计赚到的金币升级，解锁雇工、工具上限，田边陆续出现篱笆、谷仓、风车、灯笼、垂柳、远塔……
8. 开局 2×2 块地、50 金币，地可以一路开垦到 3×4。

**存档**：自动存在本机浏览器（localStorage），每 10 秒一次，切到后台/关闭页面时也会存。离开后再回来，会按离开时长（最多 2 小时）结算雇工替你干的活：「你不在时，雇工替你挣了 X 金币」。设置（右上角齿轮）里可以切换动效强度、清空存档。

## 如何本地运行

浏览器直接双击 `index.html` 打不开 ES 模块，需要起一个本地静态服务器：

```bash
cd 本仓库目录
python3 -m http.server
```

然后打开 <http://localhost:8000>。手机和电脑在同一个 Wi-Fi 下，也可以用电脑的局域网 IP 访问。

## 如何开 GitHub Pages

1. 打开仓库的 **Settings → Pages**
2. **Source** 选 **Deploy from a branch**
3. Branch 选 **main**，目录选 **/ (root)**，点 Save
4. 一两分钟后，页面顶部会给出网址，形如 `https://<用户名>.github.io/<仓库名>/`

所有路径都是相对路径，放在子目录下也能正常运行。

## 文件结构

```
index.html        页面骨架
css/style.css     全部样式与 CSS 动画
js/config.js      所有数值（作物、价格、工具、雇工、庄园等级）——调平衡只改这里
js/state.js       游戏状态与派生数值
js/crops.js       播种、生长、收割、开垦、解锁
js/market.js      集市价格浮动、卖出、订单
js/tools.js       工具升级
js/workers.js     雇工雇佣、升级、走路干活的 AI
js/game.js        每帧推进与离线快进
js/save.js        存档 / 读档 / 离线收益
js/art.js         线描美术（作物、工具、雇工、景物，全部是 SVG 字符串）
js/field.js       田地与雇工的渲染
js/fx.js          动效：粒子、飞行图标、数字滚动、升级光效
js/ui.js          HUD、标签页、面板、弹层
js/main.js        启动与主循环
sim/balance.mjs   无界面平衡模拟：node sim/balance.mjs
```

## 平衡模拟

```bash
node sim/balance.mjs
```

用一个“普通玩家”机器人跑 20 个随机种子，输出第一个收割工、种地工、挑夫等的中位解锁时间，以及第 10 分钟起完全不操作时雇工的产出。
